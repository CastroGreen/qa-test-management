# Jornada de execução de testes

Este documento apresenta a jornada principal considerada na arquitetura.

O fluxo representa a execução de um caso de teste automatizado, o retorno do resultado e o registro de um possível bug no Jira.

## Fluxo

Analista de QA
→ Sistema de Testes
→ Robot Framework
→ Python
→ Resultado
→ Jira, caso exista uma falha
