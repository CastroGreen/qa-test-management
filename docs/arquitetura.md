# Arquitetura

Este documento apresenta uma visão geral da arquitetura proposta para o sistema de gestão e automação de testes.

O sistema tem como objetivo apoiar o time de QA no gerenciamento de casos de teste, execução de testes, registro de resultados e acompanhamento de falhas.

As principais tecnologias e integrações consideradas são:

- Robot Framework
- Python
- Jira
- Sistema de gestão de testes
